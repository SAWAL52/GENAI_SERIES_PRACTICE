# GenAI Series

This repository contains my code and Jupyter notebooks as I learn about Generative AI. I'll be adding examples, trying out different libraries, and documenting what I learn along the way.

## What's inside?

- `notebooks/` — Jupyter notebooks and experiments
- `requirements.txt` — Python libraries used in the project

## Getting started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/GENAI_SERIES.git
cd GENAI_SERIES
```

Create and activate a virtual environment:

```bash
python3 -m venv env
source env/bin/activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open a notebook from the `notebooks` folder to get started.

## Note

Some notebooks may require API keys or additional configuration. Keep your API keys in a local `.env` file and don't commit that file to GitHub.
